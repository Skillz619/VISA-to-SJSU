
# 📝 CPT Submission Guide — Department of Computer Engineering (CMPE)

### ✅ Before You Start

| ❗ Important Notes |
|-------------------|
| **1.** All CPT requests must be submitted via iSpartan: [iSpartan CPT Request Portal](https://globalspartans.sjsu.edu/istart/controllers/client/ClientEngine.cfm?serviceid=EFormCurricularPracticalTrainingRequest1ServiceProvider). PDF forms are no longer accepted. |
| **2.** You must cancel and re-submit the CPT request if ISSS flags any issues or missing info. |
| **3.** CMPE students are not allowed to take up CPT **and** on-campus jobs **at the same time**. |
| **4.** Only **3 CPT authorizations** are allowed throughout the MS degree. |
| **5.** CMPE CPT applications must be submitted **by the last day to add classes** (Fall/Spring). No late petitions will be accepted. |
| **6.** If taking <9 units in Fall/Spring, submit **Reduced Course Load (RCL)** request to ISSS **at the same time**. |

---

## 📌 Step-by-Step Instructions for CPT Submission

### 🔹 Step 1: Register for Internship Course
- **Register for CMPE 298i** before beginning the CPT application.

---

### 🔹 Step 2: Complete the iSpartan eForm

| Field | What to Enter |
|-------|---------------|
| Department Advisor | - **MS SE:** Dan Harkey  <br> - **MS CMPE:** Haonan Wang <br> - **MS AI:** Magdalini Eirinaki |
| Advisor Email | `sjsu-cmpe-isss-eforms-group@sjsu.edu` (❗ Not your individual advisor's email) |

---

### 🔹 Step 3: Upload Required Files to iSpartan eForm

#### 📁 **File 1: Employment Offer Letter**
Upload under **"Upload CPT Employment Offer Letter"**.

| Offer Letter Requirements |
|---------------------------|
| 🏢 On **official company letterhead** |
| 📅 Dated within **last 3 months** |
| 💼 Include job **title** and **description** |
| 📍 Include **physical address** (street, city, state, ZIP) |
| ⏰ Include **start and end dates** |
| 🕒 Include **hours per week** |
| 🖥️ If remote, must state remote work + exact remote address |

---

#### 📁 **File 2: Department Required Documents (Combined as ONE PDF)**  
Upload under **"Upload Document Required By Your Department"**.

| File Description | Instructions |
|------------------|--------------|
| 3.1 Admission Letter | Scan front and back pages |
| 3.2 Unofficial Transcript | Download from MySJSU |
| 3.3 Course History | Screenshot + save as PDF |
| 3.4 Admission Prerequisites (If Applicable) | Include proof if you fulfilled conditions externally |
| 3.5 Program of Study (POS) | Use appropriate POS template below: |

#### POS Templates:
| Program | Template |
|---------|----------|
| MSAI | [MSAI-LastName-FirstName-POS-v1.docx](https://sjsu.edu/...) |
| MSCMPE | [MSCMPE-LastName-FirstName-POS-v1.docx](https://sjsu.edu/...) |
| MSSE | [MSSE-LastName-FirstName-POS-v1.docx](https://sjsu.edu/...) |

---

### 👨‍🏫 Step 4: Advisor Review
- Advisor **reviews your application** once received via iSpartan.
- If complete, **advisor approves**, and it is routed to ISSS.

---

### 📬 Step 5: ISSS Review & Approval
- ISSS **reviews the request**.
- If approved, you receive **formal CPT authorization**.
